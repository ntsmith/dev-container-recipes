# Jekyll Dev Containers

Static site generators using Jekyll for building markdown-based websites.

## Available Containers

### jekyll_minimal

Basic Jekyll setup for simple static sites.

### jekyll_markdown

Enhanced Jekyll with:
- GitHub-Flavored Markdown (GFM)
- MathJax for mathematical notation
- Minima theme

## Quick Start

```bash
code jekyll/jekyll_markdown
```

Then "Reopen in Container" when prompted. Jekyll starts automatically with live reload.

## Ports

| Port | Service |
|------|---------|
| 4000 | Jekyll server (live reload) |
