# Basic Dev Containers

Minimal configurations demonstrating different devcontainer patterns and options.

## Categories

### [alpine/](alpine/)

Lightweight Alpine Linux containers exploring various devcontainer features:
- Minimal image configurations
- User management
- Extensions and settings
- Mount configurations

### [ubuntu/](ubuntu/)

Ubuntu-based containers exploring user/permission models:
- Root vs non-root users
- Microsoft base images
- Pseudo-devcontainer workarounds

## Purpose

These containers are reference implementations for learning devcontainer basics. Each demonstrates a specific configuration pattern you can adapt for your projects.
