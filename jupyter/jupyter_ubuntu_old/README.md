# Jupyter Ubuntu (Legacy)

A minimal Jupyter notebook environment on Ubuntu.

> **Note**: This is an older configuration. Consider using `jupyter_ubuntu` for a more complete setup.

## Quick Start

1. Open this folder in VSCode
2. Click "Reopen in Container" when prompted
3. Open `Stuff.ipynb` to run the demo

## What's Included

- Ubuntu base image
- Python 3 with Jupyter
- VSCode Python and Jupyter extensions
