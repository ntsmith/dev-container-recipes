# Jupyter Dev Containers

Jupyter Lab environments for data science and analysis work.

## Available Containers

### jupyter_ubuntu (Current)

Full-featured data science environment with:
- **ML Stack**: numpy, pandas, matplotlib, scipy, seaborn, plotly, scikit-learn, tensorflow
- **Geo Stack**: GeoPandas with GDAL/GEOS support
- **LaTeX**: For notebook export and mathematical rendering
- **Finance**: yfinance for stock data

### jupyter_ubuntu_old (Archived)

Previous iteration, kept for reference.

## Quick Start

```bash
code jupyter/jupyter_ubuntu
```

Then "Reopen in Container" when prompted.
