# Python Tab Size Dev Container

Python environment demonstrating custom editor tab settings.

## Quick Start

1. Open this folder in VSCode
2. Click "Reopen in Container" when prompted
3. Open `test.py` to see custom tab size settings

## Demo

- `test.py` - Sample code showing tab/indentation settings

## What's Included

- Python 3 (Alpine image)
- Custom VSCode settings for tab size
- VSCode Python extension
