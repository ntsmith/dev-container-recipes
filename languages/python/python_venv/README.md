# Python Virtual Environment Dev Container

Python environment with virtual environment setup.

Based on https://github.com/RamiKrispin/vscode-python

## Quick Start

1. Open this folder in VSCode
2. Click "Reopen in Container" when prompted
3. Run `python demo.py` to verify the environment

## Demo

- `demo.py` - Verifies virtual environment is active

## What's Included

- Python 3
- Virtual environment pre-configured
- VSCode Python extension
