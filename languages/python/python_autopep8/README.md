# Python with Autopep8 Dev Container

Python environment with automatic PEP8 formatting.

## Quick Start

1. Open this folder in VSCode
2. Click "Reopen in Container" when prompted
3. Open `test.py` and save to see auto-formatting

## Demo

- `test.py` - Sample code demonstrating auto-format on save

## What's Included

- Python 3 (Alpine image)
- Autopep8 extension for auto-formatting
- VSCode Python extension
