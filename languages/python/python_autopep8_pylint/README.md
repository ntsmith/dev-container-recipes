# Python with Autopep8 + Pylint Dev Container

Python environment with automatic PEP8 formatting and linting.

## Quick Start

1. Open this folder in VSCode
2. Click "Reopen in Container" when prompted
3. Open `test.py` to see linting and auto-formatting

## Demo

- `test.py` - Sample code demonstrating linting and formatting
- `pylintrc` - Pylint configuration

## What's Included

- Python 3 (Alpine image)
- Autopep8 extension for auto-formatting
- Pylint extension for linting
- VSCode Python extension
