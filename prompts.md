This project is for POC code for devcontainers. Each one should set up one or more containers and provide a demo (in some manner) when launched (e.g. for db: create db and table, add data, retrieve) The projects are in various states of functioning. The devcontainers_old directory was from a previous iteration. I would like to organize what I have, fixing and expanding along the way. Each one should get a devcontainer.json, any needed dockerfiles, a docker-compose.yml (optional), a ReadMe, and a .gitignore. Please also add to claude.md to help focus our work.
